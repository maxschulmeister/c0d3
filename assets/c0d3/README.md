# c0d3 web and desktop icons

The SVG files are the sources for web and desktop branding. Mobile keeps the original assets.

Run `vp run icons:export:c0d3` to generate the PNG and ICO files, or add `--check` to verify them. macOS icons use an 824-pixel body with a 100-pixel inset on a 1024-pixel canvas.

The outlined lettering uses Inter Bold. Its license is in `LICENSE.Inter`.
